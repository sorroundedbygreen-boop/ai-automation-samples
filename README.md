# AI業務自動化 サンプル集

企業の「人手でやっている定型業務」を生成AI（Claude API）で自動化するデモアプリ3本です。
APIキーが無くても **デモモード** でそのまま動かせます。

| # | アプリ | 対象部署 | 自動化する業務 | 使っている技術 |
|---|---|---|---|---|
| ① | 社内規程Q&Aボット | 総務・人事 | 「在宅勤務は何日まで？」など規程への問い合わせ対応 | RAG（検索拡張生成）、出典の明示 |
| ② | 請求書データ化 | 経理 | 形式がバラバラな請求書の読み取り・転記・インボイス要件確認 | PDF/画像読み取り、構造化出力(JSON Schema)、プログラムでの検算、Excel出力 |
| ③ | 問い合わせ自動仕分け | カスタマーサポート | 問い合わせの分類・優先度付け・返信下書き | 分類、感情分析、エスカレーション判定、文章生成 |

## 起動方法

```
pip install -r requirements.txt
python -m streamlit run app.py
```

Windows なら `起動.bat` をダブルクリックでもOKです。ブラウザで http://localhost:8501 が開きます。

実際にAIを動かす場合は、環境変数 `ANTHROPIC_API_KEY` を設定してから起動し、左の「デモモード」スイッチをオフにします。

## 工夫したポイント（提案・面談で話すところ）

- **ハルシネーション対策**：Q&Aボットは検索した条文だけを根拠に回答し、出典の条番号を必ず表示。根拠が無ければ「総務部へ」と答える
- **AIを過信しない設計**：請求書は AI の抽出結果を「小計＋税＝合計」「明細の合計」でプログラムが検算し、合わないものを「要確認」に回す
- **人が最終判断**：返信は下書きまで。送信は担当者が確認して行う（Human-in-the-loop）
- **出力形式の固定**：JSON Schema による構造化出力で、Excel・CSV・既存システムへそのまま連携できる
- **情報セキュリティ**：法人向けAPIは入力データが学習に使われない。社内規程のサンプルにも生成AI利用ルールを入れてある

|---|---|---|

| 請求書入力 | 月300枚 × 1枚5分 → 確認だけで1分 | 約20時間/月 |

## 構成

```
app.py                  トップページ
pages/                  3つのアプリ
common/llm.py           Claude API 呼び出し（エラー処理・デモモード切替）
data/                   サンプルデータ（規程・請求書・問い合わせCSV）
```

## 実案件に広げるときの拡張案

- ① SharePoint / Google ドライブの文書を自動で取り込む、ベクトル検索に置き換える、Teams・Slack から質問できるようにする
- ② freee・マネーフォワードなど会計ソフトへの自動登録、メール添付の請求書の自動取り込み
- ③ Gmail・Zendesk・kintone と連携し、受信と同時に仕分け
